# IAM-PAM-Portfolio

### Identity & Access Management | Privileged Access Management | Active Directory | Microsoft Entra ID | CyberArk

Welcome to my IAM-PAM Portfolio!

This repository showcases my hands-on learning, practical implementations, lab exercises, troubleshooting, and documentation in **Identity and Access Management (IAM)** and **Privileged Access Management (PAM)**.

The objective is to develop practical skills in managing enterprise identities, controlling user access, securing privileged accounts, implementing authentication mechanisms, and understanding enterprise identity security.
