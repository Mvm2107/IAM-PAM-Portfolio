# Enterprise Applications and SSO

## Overview

This module covers Microsoft Entra enterprise application management, application registrations, service principals, Single Sign-On, SAML 2.0, OAuth 2.0, OpenID Connect and provisioning.

## Learning Objectives

- Understand App Registrations and Enterprise Applications.
- Understand service principals.
- Inspect application credentials and API permissions.
- Understand application roles.
- Understand SSO architecture.
- Learn SAML authentication and troubleshooting.
- Learn OAuth 2.0 and OpenID Connect.
- Understand SCIM provisioning.
- Investigate application access issues.

## Lab Environment

Application: `IAM-Lab-Test-App`

Platform: Microsoft Entra admin center

Environment: Cloud-only Entra tenant

## Practical Activities

- Inspected the Enterprise Application.
- Compared App Registration and service principal identifiers.
- Inspected certificates, secrets and federated credentials.
- Reviewed API permissions.
- Inspected existing app roles.
- Investigated application assignment and removal using audit logs.
- Inspected the provisioning configuration page.

## Lab Limitations

The test application did not have an external application backend.

Therefore, SAML/OIDC end-to-end authentication and SCIM provisioning were not implemented.

No application credentials, API permissions or provisioning configuration were created during these exercises.
